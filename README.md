# Gosuslugi Yandex Browser Extension

Расширение (Manifest V3) для Яндекс Браузера, которое:
- хранит повторяющиеся данные в справочниках (4 формы),
- добавляет кнопку "Автозаполнить из справочника" на страницах Госуслуг,
- подставляет последнее сохранённое значение по каждой форме.

## Установка
1. Откройте `browser://extensions` в Яндекс Браузере.
2. Включите "Режим разработчика".
3. Нажмите "Загрузить распакованное расширение" и выберите папку проекта.

## Формы
1. Проектировщик: ФИО, номер/дата аттестата.
2. Ответственный работник: ФИО, СНИЛС.
3. Работник: ФИО, СНИЛС.
4. Оборудование: наименование, серийный номер, номер/дата поверки.

## Примечание
DOM на Госуслугах может меняться, поэтому селекторы в `content.js` при необходимости нужно адаптировать под конкретную страницу.
